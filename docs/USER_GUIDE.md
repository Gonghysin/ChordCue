# ChordCue 使用手册

ChordCue 读取 Logic 已有和弦轨及播放头，不修改工程。安装和授权见 [安装说明](INSTALL.md)。首次启动未连接时显示原创演示和弦；点“刷新 Logic 和弦”接入实际工程。无需 MIDI Clock 或 MIDI Out。

## 谱面与数据

- 顶部中央显示当前 Logic 工程名称、拍号和实时 BPM；速度与拍号约每 0.3 秒读取一次，跟随 Logic 当前播放位置的变化。工程切换后会重新连接；控制栏未显示对应字段时以 `—` 表示未读取到。
- 顶部可切换“和弦／级数”和显示调。选择“轨道原样”保持 Logic 和弦轨的音高；“C 调”根据分析出的调性移调到 C 调体系；也可选择其他目标调。
- “调性设置”默认自动定调与转调：综合和弦组成音、持续拍数、大小调轮廓以及前后段落证据。级数统一按关系大调编号：C♯ 大调／A♯ 小调均以 `1=C♯` 表示，A♯m 显示 `6m`，F♯ 显示 `4`，G♯ 显示 `5`；小调额外注明 `6=A♯（小调）`。转位低音也按同一体系换算。
- 新版“自动检测转调”默认开启，按逐小节证据寻找段落，无需转调恰好发生在 8 小节边界。新段至少持续四小节且包含三个不同根音，短暂借用和弦通常沿用前段。关系大小调共用级数体系，不重复标为转调。可关闭检测改为全曲统一定调；已知调性可用“轨道定调”指定，转调位置可手动填写。C 调移调与级数共享同一调性体系。
- 转调标记精确到小节，短暂离调可能不标出。算法只根据 Logic 和弦轨推断，不能修复 Logic 识别错的和弦，也不能保证在缺少旋律时唯一确定关系大小调。
- 歌曲有转调而自动位置不准时，可在“手动转调点”每行填写“小节 调”，例如 `33 E♭`、`49 Am`。填写后这些标记决定后续各段的级数，直到下一个手动转调点；第 1 小节沿用自动分析或手动级数定调。
- “移调前原调”默认未指定。若 Logic 和弦轨已经被手动移调，应用无法从现有和弦反推移调前的歌曲调性；你可在这里指定原调，供显示和 PDF 导出恢复。未指定时“移调前原调”等同“轨道原样”。
- “导出 PDF”可生成和弦谱（轨道原样、C 调、移调前原调或当前显示调）及级数谱（当前显示调）。PDF 按拍分割小节，并在分析出的段落标出调性。
- 拖动窗口边缘可调整大小；窗口变窄时每行的小节数减少，变宽时增加。顶部“窗口置顶”按钮可随时切换，设置会保存；默认是普通窗口。
- 每个格子对应一小节；同一小节有多个和弦时，按起拍位置分格。分格宽度表示该和弦持续的拍数；蓝色细线表示当前播放位置。顶部以大字显示当前和弦。
- `%` 表示整小节沿用上一个和弦；小节开头的浅灰短横线表示上一个和弦延续到本小节的新和弦出现。自动识别产生的细小时间偏差会对齐到最近的整拍格，便于阅读；当前和弦仍按 Logic 播放头的精确位置判断。
- 面板每 5 秒重新读取一次 Logic 和弦轨；你在 Logic 中修改和弦后，可点“刷新 Logic 和弦”立即更新。
- 同步优先读取时间标尺上的完整播放位置；也兼容顶部只显示“小节与拍”的简洁模式。若标尺位置不可读取，则退回按拍同步。
- 若辅助功能未授权，面板显示原创演示和弦，但不会知道 Logic 播放头的位置。
- “备用输入”允许手动输入其他歌曲的和弦，例如 `1.1 C`、`1.3 G/B`、`2.1 Am7`。读取到 Logic 和弦轨时，实时数据优先。

## 局域网投放

1. 顶部点“局域网投放”，再点“开启投放”。默认关闭，不随应用启动自动开放端口。
2. 将面板显示的完整 `http://局域网IP:端口/join/随机路径/` 链接发给同一 Wi-Fi 或有线局域网中的其他人。端口由系统分配；停止再开启会产生新链接。可点“复制链接”或“预览”。多个网卡时会显示多个地址，选择其他设备能访问的那个。
3. 对方用电脑、平板或手机浏览器打开，无需安装 ChordCue。可选择和弦／级数、轨道原样或目标调、全屏和是否跟随滚动。这些设置只保存在对方浏览器，不改变主机或其他人的显示。
4. 主机的当前工程、原始和弦、调性段落和播放头会推送给浏览器。主机的级数定调及手动转调点决定公共分析结果；主机的“显示调”“谱面”不影响访客。和弦轨修改按定期刷新生效，点“刷新 Logic 和弦”可立即读取。
5. 点“停止投放”立即断开访客，原链接失效。页面会提示断连，不继续预测播放位置。最多同时接入 24 个跟谱页面。

网络访问只提供读取，不提供远程播放、编辑或写入接口；只接受本机和私有／链路本地地址。链接中的随机路径用于防止随意访问，不是加密连接。不会连接外部服务或上传谱面。访客只能看到工程名称、谱面、调性及播放信息，看不到工程文件路径。

若打不开，先确认两台设备在同一局域网，且 Wi-Fi 没有开启访客隔离。如果 macOS 防火墙询问是否允许 ChordCue 接受传入连接，请允许。网络切换后停止再开启投放以更新地址。只有 `127.0.0.1` 链接时表示尚未找到可供其他设备访问的 IPv4 地址。

### 同步精度

- 投放时播放头目标轮询间隔为 50ms；关闭后恢复 150ms。每个样本带主机单调时钟时间戳和辅助功能读取耗时。
- 浏览器测量时钟接口往返时间，使用近期低延迟样本校准两端时钟，并定期重新校准。页面显示“网络往返”“读取耗时”，这两项不能等同于总同步误差。
- 在精细位置可读、连续前进且没有跳转时，优先按 Logic 提供的 BPM 进行最长 150ms 的短时预测；BPM 不可读才退回实测位移速度。采样年龄超过 200ms 不再预测，超过 500ms 则提示位置过期。预测没有独立 BPM 分析，也不累积自由运行的播放时间。
- 停止、定位、循环回到前面和工程重新连接都会放弃旧速度，跟随新样本。只有小节／拍可读时降级为按拍同步，不假装具有 tick 精度。
- 精细分拍和短时预测沿用现有 Logic 位置字段约定；预测目前仅在四分音符作拍单位时启用。历史变拍号地图尚未接入，不能宣称跨变拍号的拍内布局已完全准确。
- 辅助功能响应、Logic 自己更新界面的速度、Wi-Fi 抖动及浏览器绘制都会影响最终误差。因此这版提供低延迟视觉跟谱，不承诺采样级同步；实际异机误差仍需在演奏所用的网络和设备上测量。

## 同步节拍器

本机顶部新增“和弦谱／节拍器”页面切换。局域网浏览器顶部也有相同的两页；本机节拍器无需开启投放即可使用，其他人仍通过投放链接进入。

1. 接上有线耳机，进入“节拍器”页面，点“开启声音”。声音默认关闭，初始音量 35%；每个人需要在自己的设备上点击开启。
2. 选择“经典节拍器”或“鼓机节拍器”。经典模式普通拍和重拍使用不同音高的点击音；鼓机由本设备合成底鼓、军鼓和踩镲，不下载音频素材。
3. 拍号自动跟随 Logic。支持 1–12 拍、四分音符为拍单位，如 2/4、3/4、4/4、5/4、7/4。每个拍点是一根三格柱，自下向上亮 0／1／2／3 格分别为不响／轻拍／正常／重拍；点击格子选择强度，再点最高亮格降低一档。鼓机每柱还可独立选择底鼓、军鼓或踩镲。其他分母的拍号显示提示，暂不出声。
4. 选择“八分音符”后，4/4 显示 8 根柱，3/4 显示 6 根；数字代表整拍，& 代表后半拍。“按拍”只显示整拍。各音色／拍号／细分组合的配置独立保存，旧配置的不响／普通／重拍分别保留为 0／2／3 格。开启声音会显示启动状态，若音频启动超过 3 秒，会显示原因并允许重试。
5. “试听一拍”用于确认音色与音量，不要求 Logic 播放，也不会开启持续节拍器。Logic 停止时保持安静；播放开始后从下一个可提前排程的拍点加入。
6. 输出设备延迟会尽量自动补偿，也可通过“额外补偿”在 ±150ms 内微调：正值提早，负值推迟。设置只影响自己；换耳机或声卡后需重新校准。
7. 开启后切回和弦谱，节拍器会继续跟随 Logic，可同时看谱、听节拍。应用和浏览器顶部都有独立“开启／关闭节拍器”按钮；细分、音色和音量仍在节拍器页设置。浏览器进入后台、锁屏、关闭页面、断连或同步数据过期时停声；锁屏或浏览器进入后台后需要重新开启。本机在不同应用间切换无需主动关闭节拍器。手机和平板使用时请保持页面在前台、屏幕不锁定。

### 声音同步的边界

- 节拍器每 25ms 检查待排程的拍点，提前送给 Web Audio 音频时钟；不依赖画面刷新或在 `setInterval` 回调当场发声。每次重新以 Logic 样本计算，不累计独立播放时间。
- 浏览器通过已有往返校时同步主机时间；本机通过 WKWebView 本地桥进行同样校时。可用时采用 `getOutputTimestamp()` 映射设备输出时钟，否则使用浏览器报告的延迟估计。
- 已确认的停止、跳转、循环回退、工程切换与拍号变化会取消待播声音；同步样本过期 350ms 时停止排程。短暂抖动不再取消正在响的音符，只校正未来拍点。精细位置不可读时不出同步声音，避免把按拍数据当作精确时钟。
- 新版提高点击与鼓音电平，个人音量滑块的设置保留；采用下一拍游标避免靠近拍点时漏排。迟到 20ms 以内可补排，超过则跳过，避免密集补响。仍需对实际耳机响度和断续情况试听确认。
- 短时跨小节排程沿用最近收到的 Logic 拍号与速度；尚未读取完整的未来速度／拍号地图，因此突变边界、突然开始的第一拍及网络抖动仍可能有误差。辅助功能读数本身有延迟，输出延迟估计也不是声学测量。
- 这是跟随 Logic 的个人节拍提示，不包含伴奏或人声音频。当前不能承诺达到专业无线耳返／采样级同步精度；多人实际耳机出声偏差需要现场测量和校准。

## 使用边界

Logic 查询在后台进行，启动时会先显示窗口。若 Logic 暂时无响应，面板会提示读取超时并重试；仍可调整窗口和导出已有谱面。

应用读取的是 Logic Pro 的辅助功能界面信息。请保持工程在 Logic 中打开，并让全局和弦轨可见。若 Logic 改版后界面信息变化，需要更新读取逻辑。当前谱面以固定拍号的小节格呈现；变拍号不会影响按小节高亮，但不显示拍号变化。
